## 2. 时间网格：BPM 到底记 91.4 还是 183？

两种都"对"，但会写出完全不同的 beat 数值。判据用**双证据**：

```
① 鼓点网格搜索：182.9 BPM 得分 0.674（第二名 0.33）
② 歌词整拍率：91.43 BPM + phase 0.09 s 时，48 句里 41 句落在 ±0.06 拍内
→ 取 91.43（"一拍"= 一个 4 分音符），鼓点落在 0.5 拍（八分）
```

- `period = 0.65628 s`，`beat 0 = 0.090 s` → `info.yml offset: 0.09` / `META.offset: 90`。
- **为什么不用 183**：183 下歌词会落在偶数拍、句尾在 1/2 拍上，读起来不整；91.43 下每句起点都是整数拍，写谱时 `bt(n)` 就够了。
- ⚠️ 用错记法不会报错，只会**整体时间差一倍**——这是本仓库 R 系列之外最容易犯的"静默错误"。

## 4. 设计：把"轻快的节拍"和"空房间"叠在一起

### 4.1 母题

封面是公寓立面 + 粉色横幅。歌反复问"报告一下你在哪"。
→ 演奏线 = 窗台上**那部不会响的手机**；表演线 = 房间的**门框 / 吊灯 / 钟面**。
粉色只作**信号色**（`colorEvents`），出现在"期待"的段落（Pre、Rap、副歌前），不是装饰。

### 4.2 线的角色（12 条，只有 1 条承载真音符）

| 线 | 数量 | 角色 | 关键参数 |
|---|---|---|---|
| `Main` | 1 | 唯一演奏线 | y −110~−160，rotate −26°~+26°，speed 8.8→11.8，粉色/白色切换 |
| `Star1-3` | 3 | 六星芒（0/60/120°）共点于上方，作"吊灯/窗格" | alpha 22~175，scaleX 0.85，逐 1 拍正弦呼吸 |
| `FrameL/R` | 2 | 门框竖线 | 段落切换时从屏幕外 `moveX ×2.8` 飞入（easing 20） |
| `Skyline1-3` | 3 | Verse A 的"城市天际线"横向扫过 | scaleY 0.02（压成一条线） |
| `Pen` | 1 | Verse B 的"笔"，随人声左右写字 | scale 0.22×0.02，30 段位移 |
| `ClockHand` | 1 | Rap 段"三分钟"的指针 | 26 拍旋转 100°，alpha 170→0 |
| `Lyric` | 1 | 中文歌词 | y −330，26 px，逐句打字机 + 0.35 拍淡出 |

### 4.3 逐段手法（与音乐事件的对应）

| 段落 | 音乐事实 | 手法 |
|---|---|---|
| Intro | 0–5 s 只有 pad | 落 9 颗假 Drag 当"雨点"；标题打字机；真音符 0 |
| Verse A | 每句 8 拍、句尾长音 | 8 分交替（−184/+184 → ±306 → 阶梯），**句尾改 Hold 2 拍** |
| Verse B | "只有纸和笔" | Pen 线随字横移；8 分 + 每小节 2 颗 16 分过门 |
| Pre 1 | 三次"寂寞"短句 + 一个高音长音（质心 2990 Hz） | 三连 Drag 写"寂寞"；高音处 `H(70,72.5)`；**73 拍留空拍** |
| Chorus 1 | 10 句 × 4 拍，句尾重音 | 首拍双押（±306/±184）→ 16 分 → 句中 Hold（锁指）→ 句尾 Flick/Hold 交替 |
| Rap | 念白密集、情绪最"急" | 16 分 Drag 蛇形（`sin(k·0.55)`）+ 每 8 格一颗 Tap；**7.2 NPS 全曲最高** |
| Bridge | 反思、拉长 | 表演线 alpha→22（只留主线）；Main ±26° 慢摆；长 Hold；**166–168 零音符 + 6 颗假雨** |
| Pre 2 | 与 Pre 1 同构 | 完全镜像（手型取反），密度略升 |
| Chorus 2 | 终副歌 | 母题复用 + 门框飞入 + 星芒反转到 360°+；221 拍速度脉冲 11.8→8.4→11.2；225.5 落地和弦 + shockwave |
| Outro | 最后一句 + 淡出 | 主线 rotate 到 88° 下坠、alpha 归零 |

### 4.4 特效（只有 3 类，且都可关）

`vignette`（全曲 0.35/radius 90）· `glitch`（113 拍转场，power 0.42）· `shockwave`（74 拍与 225.5 拍）。
**关掉 shader 画面仍成立**——所有结构由线与 note 承担。

## 6. 复盘

**做对了**

1. 先用 `extract_tags` + 静音检测，10 分钟拿到"真实格式 / 双语歌词 / 无封面 / 24 s 空白"四个关键事实。
2. 用"鼓点得分 × 歌词整拍率"定 BPM 记法，整张谱的时间没有一处需要手调。
3. 副歌母题复用：两段副歌用同一套手型，只换构图，玩家第二遍就有肌肉记忆。
4. `approach_visible_ratio` 0.84→0.986 是靠**降速**拿的，不是加密度——手感没变差，画面先变满。
5. 把"留白"写进剧本：Intro 0 音符、Bridge 6 拍零音符、Outro 只留一颗落地音。

**还不够好（下一版要改）**

1. **平均 NPS 4.0 偏保守**，Lv13 的手感标准更接近 4.5–5.0；可以在 Verse 句中加入 16 分，而不是只在句尾。
2. **Hold 只占 6.8%**，抒情曲可以到 10–15%；副歌的"锁指"可以更频繁地出现在第 2 拍。
3. **事件密度 2.0/音符** 低于社区中位（3–6），线姿态变化偏"段落级"，缺少 1/8 拍级的细节抖动；
   下一篇应给 `Star` 加一层 `eventLayers`（加法层）做高频呼吸，而不是继续加密主曲线。
4. 画面在 Verse 段仍偏空（可见 note 1–2 颗）——这是 91 BPM 的物理限制，
   正解是加"装饰物"（假雨/光点），而不是硬提密度。
