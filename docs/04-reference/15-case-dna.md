# 15 · 案例：D/N/A —— 24 条线怎么让"表演不单调"

## 1. 硬数据

| 项 | 值 |
|---|---|
| 判定线 | **24 条**，其中**3 条承载音符**（101 / 98 / 426） |
| 音符 | 696（Tap 278 / Drag 197 / **Hold 179** / Flick 42）→ Hold 占 **26%** |
| 事件 | 1066（1.5 / 音符，8.3 / 秒） |
| 贴图 / shader | **0 / 0**，`extended` 只用了 `inclineEvents`（且值为 0） |
| 密度 | 均 5.65 NPS，峰 26 |
| 难度 | HD Lv.12，实际手感被作者吐槽"长得像 IN" |

**第一个结论**：24 条线不是"演出堆出来的"，而是**计数/分轨**——3 条线分走所有音符，
其余 21 条里只有 1 条（line 7，288 事件）是真正的表演线，剩下的多半是"备用的、按段落出场的"。

## 2. 它解决"表演单调"的四个手段

### 2.1 承载线只做"小幅高频呼吸"

line 2（426 音符）的事件：

```text
moveY   -300 ↔ -350    每 2 拍一次，easing 8 (OutCubic)
rotate   0 ↔ +4 ↔ -4   每拍交替，easing 8 与 2 (OutSine) 交替
```

- 位移 50 px、旋转 ±4°，**幅度小到不影响落点预判**，但画面上线一直在"呼吸"。
- 高频（每拍）意味着玩家眼睛能感到"它在跟着歌动"，而不是每 4 拍跳一下。

> 这是**最关键的一条**：承载线的表演要"高频 + 小幅度"，表演线才用"低频 + 大幅度"。

### 2.2 表演线：扫入 + 竖立 + 频闪

line 7（20 音符，288 事件）：

```text
moveX   -680 → -200   每 2 拍一次，easing 8     ← 快速扫入，停在偏左
rotate   90                              ← 竖起来（门/帘）
alpha   255 → 0       每拍一次（140 个 alpha 事件）  ← 频闪
```

### 2.3 判定线的"数量与角度"随段落变

逐帧看（35 / 50 / 62 / 75 / 90 / 105 s）：

| 段落 | 线的形态 |
|---|---|
| 35 s | 3 条水平线 |
| 50 s | 5 条水平线 + 竖线分割 |
| 62 s | 水平 + 垂直**网格**（分区演奏感） |
| 75 s | 回到 3 条，右侧留一条竖线 |
| 90 s | **2 条大角度倾斜**（整组线斜切，画面突变） |
| 105 s | 3 条水平回归 |

→ **"线的数量"和"线的角度"本身就是演出**，不需要每条线都在转。
一张谱里如果 6 条线从头转到尾，观众只会记住"一直在转"。

### 2.4 承载线轮班

3 条承载线不是同时开工：主线（426）打主体，另外两条（101 / 98）在特定段落接班，
交接时用 `alpha` 切换 + 一个重音。**多线承载的意义不是"同时打"，而是"换手不换观感"。**

---

## 3. 可以直接抄的四条

1. **承载线：每拍 ±4° / ±50 px 的呼吸**，easing 8 与 2 交替，别用线性。
2. **表演线：竖线（rotate 90）+ 扫入（moveX ±680）+ 频闪（alpha 每拍 255→0）**，
   三件套换着用，不要一条线全占。
3. **每两个段落换一次"线的形态"**：水平 → 网格 → 大倾斜 → 回归；
   形态变化本身就是最强的转场。
4. **多线承载 → 轮班**：主线 + 副线分段落，交接点配重音，不要两条线同时满负荷。

## 4. 和我们的《灵魂伴侣》对照

| 维度 | D/N/A | 我们的 v1 | 改进方向 |
|---|---|---|---|
| 线数 | 24（3 承载） | 12（1 承载） | 加到 19，仍只 1 条承载（可拆） |
| 承载线呼吸 | 每拍 ±4° | 段落级 ±26° | **幅度过大、频率过低** → 改成段落级大姿态 + 每拍微呼吸 |
| 表演手段 | 扫/竖/闪/网格/倾斜 | 六星芒自转 | 已补扫线 2 条、频闪 1 条、门框飞入、尾奏三弦 |
| 事件密度 | 8.3 / 秒 | 10 / 秒 | 量够，但分布集中在段落边界 |
| Hold | 26% | 6.8% | 抒情段落可再提 |

> 结论：**"表演单调"的根因不是线少，而是"所有线用同一种运动方式"**。
> 解法是把运动方式分类（呼吸 / 扫 / 闪 / 倾斜 / 开合），每段挑 1~2 种。
