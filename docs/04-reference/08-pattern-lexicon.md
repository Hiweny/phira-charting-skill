# 08 · 技法词典与手感编排

> 这份文档解决一个问题：**谱面"能打"之后，怎么让它"好打、好看、有情绪"。**
>
> 结论先行：高级感不是堆音符，而是**技法密度 × 段落对比 × 判定线运动**三件事同时成立。
> 参考谱《巴拉莱卡》55% 的音符处在多押里、有 47 处轮指型转换；只有 Tap 一条直线的谱，
> 即使 NPS 一样，也会被判为"八股"。

---

## 1. 四个音符原语

| 类型 | 值 | 手感 | 适合表达 | 常见误用 |
|---|---|---|---|---|
| Tap | 1 | 点击，最直接 | 主旋律、字头、重音 | 全谱 85% 以上 → 单调 |
| Drag | 4 | 按住/划过即可，判定松 | 铺面积、拖腔、滑音、过门 | 当作 Tap 用，导致"手指放上去就行" |
| Hold | 2 | 按住到结束 | 长音、呼吸、锁指 | 在快速字句里硬塞 → 手感黏 |
| Flick | 3 | 向上/任意方向甩 | 句尾重音、段落收口、情绪爆发 | 每拍都放 → 手忙脚乱 |

**配比不是难度指标，是风格指标。**
技术向可以 Tap 主导（55~65%）；演出向可以 Drag 主导（40%+）；
抒情/叙事曲适合 **Tap 65~72% / Drag 15~22% / Hold 5~10% / Flick 3~6%**。

## 2. 组合技法（真正决定"像不像成品谱"）

### 2.1 双压 / 多押（Chord）

同一拍两个及以上音符同时落下。

- **音乐位置**：重音、和声进入、鼓的 Crash、句子最高音。
- **写法**：

```python
N(main, T, b, -200)
N(dual, T, b,  200)      # 同一 beat，不同线
```

- **护栏**：同一拍的和弦音放在**不同判定线**最容易读；同线异 x 也可以，
  但 x 间距要 ≥ 200，否则手指会打架。
- **密度**：抒情段每 2~4 小节一次，副歌每小节一次即可。

### 2.2 轮指（Trill）

两手/两轨在极短间隔内交替，形成"颤"的听感。

- **音乐位置**：桥段的留白、长音尾、情绪悬置处。
- **写法**（0.25 拍交替，反向音符更有"翻涌"感）：

```python
for k in range(8):
    N(dual, T, b + k * 0.25, -150 if k % 2 == 0 else 150, above=2)
```

- **护栏**：两条 x 的间距 ≥ 240；速度不要低于 1/4 拍，
  否则在 60~80 BPM 的曲子里会变成"糊成一片"。

### 2.3 纵连（Jack）

同一轨连续快速点击。

- **音乐位置**：说唱段落的咬字、鼓点密集处。
- **写法**：`B(bar)+3.0` 起，每 0.25 拍一颗，连续 2~3 颗。
- **护栏**：**不要和另一条线的四连音同拍叠加**。这是最常见的"峰值 NPS 爆炸"来源。
  每两小节做一次就够；连续超过 4 颗会疲劳。

### 2.4 阶梯（Stair）

音符沿一条斜线均匀上行/下行，视觉上像台阶。

- **音乐位置**：音高爬升、段落冲顶、预副歌。
- **写法**：

```python
for k in range(6):
    N(dual, T, b + k * 0.25, -300 + k * 100)   # -300 → +200
```

- **护栏**：每颗 x 递增 ≥ 80；终点不要贴屏幕边缘（留 80px）。

### 2.5 锁指交互（Hold + Tap）

一只手长按 Hold，另一只手继续打同一条线上的 Tap。

- **音乐位置**：持续低音/和声铺底 + 主旋律进行；副歌的"锚"。
- **写法**：

```python
N(dual, H, B(bar), -330, end=B(bar) + 2.2)   # 锚
N(dual, T, B(bar),  200)                     # 同拍另一颗（同线异 x 合法）
```

- **护栏**：Hold 的 x 放在 ±320~360 的边缘位，Tap 放在 ±200 以内，
  中间留出 120px 以上的"手指通道"。

### 2.6 滑条带（Drag Ribbon）

一串 Drag 在两条轨道间来回，负责"铺画面"，不增加判定压力。

- **音乐位置**：副歌、间奏、需要画面流动但不想加难度的段落。
- **写法**：

```python
for bar in chorus_bars:
    for off, x in ((0.5, -170), (1.0, 170), (2.5, -170), (3.0, 170)):
        N(dual, D, B(bar) + off, x, end=B(bar) + off + 0.30)
```

- **护栏**：Drag 的 `end` 必须晚于 `start`；同时不要与同一线的 Tap 落在
  0.1 拍以内的非整格位置（会读成双押但不是双押）。

### 2.7 反向音符（`above=2`）

音符从判定线另一侧落下，画面会"翻面"。

- **音乐位置**：终副歌、桥段、需要"世界颠倒"的瞬间。
- **写法**：`N(spine, T, b, x, above=2)`。
- **护栏**：官方语义是 `1=正向、2=反向，其它值按正向`。
  反向线最好单独一条（如 Spine），不要和正向线共用，否则读谱会乱。

### 2.8 假音符（`isFake=1`）

不参与判定，只做演出（间奏、转场、视觉引导）。

- **护栏**：只放在**已经可见**的线上；放在 alpha=0 的线上会变成"隐藏音符"，
  自检会报 `hidden_notes`。假音符数量控制在个位数。

## 3. 音节驱动：让密度跟着人声走

固定"每小节 8 颗"是模板感的根源。更自然的做法是：

```
每个字 = 一颗音；句长决定密度；句间空隙决定 Hold。
```

```python
n    = len(去空格后的歌词)
b0   = beat_of(t0 + 0.02)
span = beat_of(t1 - 0.10) - b0
step = clamp(span / n, 0.25, 0.90)     # 每颗音占多少拍
```

- `step` 小 → 字密、情绪急；`step` 大 → 字疏、留白多。
- 句尾 `gap >= 1.15` 拍时把最后一颗改成 Hold，天然形成呼吸。
- 主歌用 `rise / fall` 轮廓，副歌用 `arc`（先上后下），桥段用 `wave`（窄轨摆动）。

## 4. 歌词嵌入：三个必须做到的细节

1. **逐字跟拍**：每个字的显示时间 = 对应音符的时间，别整句一次性砸出来。
2. **停留上限**：最后一个字之后最多停 **1.15 拍**，然后 0.35 拍淡出。
3. **位置避开音符**：放在画面下方（y ≈ -300~-360）最稳；主歌/副歌只做
   10~40px 的轻微位移，不要整块跳到屏幕另一边。

实现要点（chart_builder）：

```python
# 每个字一次极短 typewriter：到点瞬间铺满前缀
text.add_text(b, b + 0.03, prefix + ch, from_text="")

# 每句一组 alpha：淡入 → 停留 → 淡出
ta += [(b0 - 0.22, 0), (b0, 255)]
ta += [(hold_end, 255), (hold_end + 0.35, 0)]
```

> 坑：`from_text` 非空且目标串更长时，RPE 会按"目标长度 × 进度"截断，
> 出现"字变少"的闪烁。用 `from_text=""` + 极短时长最稳。

## 5. 判定线舞台：不能永远水平

| 段落 | 建议姿态 | 目的 |
|---|---|---|
| 主歌 | −14°~+20°，缓慢摆动 | 不安、漂泊 |
| 副歌 | 8°~12°，两条线交叉 | 开阔、对唱 |
| 桥段 | **75° / 105° 竖立成门** | 空间骤然收紧 |
| 副歌 2 | **62° 斜切** | 与第一段副歌区分 |
| 终副歌 | 反向线托底（`above=2`） | 情绪翻转 |
| 尾奏 | 逐步转到 **90°** 并下坠 | 月落、收束 |

**位移预算**：`moveY` 至少跨 200px、`moveX` 至少跨 120px，
否则在实机里"看不出来在动"。但同一段里不要同时大幅旋转 + 大幅位移，
会晕。

## 6. 段落密度模板（77 BPM 实测）

| 段落 | 时长 | 音符数 | 均 NPS | 说明 |
|---|---|---|---|---|
| Intro | 12s | 20~30 | 2 | 只给动机，不铺满 |
| Verse 1 | 25s | 100~110 | 4.1 | 音节驱动 + 句尾 Hold |
| Chorus 1 | 25s | 135~145 | 5.5 | 加滑条带 + 锁指锚 |
| Bridge | 12s | 25~30 | 2.2 | **主动做减法**，留白 |
| Verse 2 | 25s | 130~145 | 5.5 | 比主歌 1 多一层交互 |
| Chorus 2 | 25s | 135~145 | 5.5 | 换构图（斜线） |
| Final | 25s | 150~160 | 6.2 | 三线全开 + 反向 |
| Outro | 19s | 5~10 | 0.4 | 长音收尾 |

> 峰值控制在 **11~13 NPS（1 秒滑窗）**。超过 15 通常是纵连和另一条线的
> 四连音叠在同一拍上，先减层，不要先降速。

## 10. 单 Play 线 + 零音符演出线（v4/v5 实测）

> 适用场景：抒情 / 叙事曲，玩家需要一个稳定的"乐器键盘"，同时希望画面有几何表演。
> 结论：**一条线承载全部音符，其余线一律零音符**，读谱成本最低，也最容易做出"像在演奏"的手感。

### 10.1 分工

| 线 | group | 音符 | 作用 |
|---|---|---|---|
| Main | Play | 全部 | 唯一判定线；7 个固定轨道 ±280 / ±140 / 0 |
| GateA / GateB | Perform | 0 | 与 Main 组成 6 条辐条（六星芒）或垂直门 |
| Star | Perform | 0 | `Pictures/hexagram.png` 贴图，反向自转 |
| Tunnel | Perform | 0 | `Pictures/tunnel.png` 贴图，透视纵深 |
| Ring | Perform | 0 | `Pictures/ring.png`，重音脉冲 |
| Lyric | UI | 0 | 逐字歌词 |

校验器只应在**完全没有演出线**时报警；"只有 1 条线承载音符"本身是正确设计，不是缺陷。

### 10.2 六星芒

- Main 在桥段旋到 **90°**（垂直门），间奏再转满 **360°**。
- 两条零音符线分别停在 **120° / 240°**，与 Main 的 90° 各差 60°，
  三条线 = 6 条辐条，正好是六星芒。
- 贴图 `hexagram.png` 用两个等边三角形（`tri(-90)` / `tri(90)`）各画 3 条边，
  顶点加圆点；glow 12px + core 3px，透明度别超过 120，否则抢音符。
- 让贴图**反向自转**（Main +360° 时 Star 走 −45°→−134°），两条运动方向对切，
  比同向旋转更有"齿轮咬合"的几何感。

### 10.3 透视隧道

- 自绘 1600×1200：一个灭点 + 12 条放射线 + 一串按 **1.42 倍**递进的矩形框，
  框的 alpha 随高度 16→80，模拟"越近越亮"。
- 用 `scaleXEvents` / `scaleYEvents` 从 0.78 推到 1.45 / 1.62，制造镜头推进；
  再叠一点 `moveX` 左右漂移（±30px），画面立刻从"贴纸"变成"手持镜头"。
- 只在副歌 2 / 终副歌出现，alpha 峰值 ≤ 62；间奏必须收掉，否则会与六星芒打架。

### 10.4 垂直门与"落月"

- 桥段 `rotate` 用 **`easingType=20`（OutBack）** 从 0° 甩到 90°，
  引擎自带过冲回弹，比手写 96° 假过冲更自然。
- 竖线期间 x 必须收窄到 **±280**：屏幕高度有限，±420 会顶出画面。
- 结尾从 360° 走到 450°（月落），用 **17（InExpo）** 加速下坠，
  最后 1 小节再缓出停住，情绪才"落"得下来。

### 10.5 长 Hold 会伪装成"第二条判定线"

- 长光束在低透明度下极易被误读成另一条判定线，直接破坏"只有一条线"的读谱。
- 约束：普通 Hold ≤ 0.5 拍；锁指锚 Hold ≤ 0.4 拍且每 4 小节才一次；
  `alpha` 降到 225~228。
- 如果画面仍出现"多余横线"，先查 Hold，再查是否残留了零音符的 `line.png` 演出线。

### 10.6 手感量化（v4/v5）

| 指标 | 实测 | 含义 |
|---|---|---|
| notes | 619 | 10.7 notes/小节，对标 DNA Lv.13 的 11.15 |
| avg NPS | 3.38 | 落在 Lv.12~13 区间 |
| 滚动 1s 峰值 | ≈8 | 冲刺段可读 |
| 相邻位移 p90 / max | 560 / 840 px | 最多跨 2 个轨道，不"瞎飞" |
| 和弦音占比 | 26% | 重音有厚度，但不糊 |
| 同 x 短间隔冲突 | 0 | 不出现"手指打架" |
| hidden / offscreen | 0 / 0 | 竖线、旋转后仍全部可见 |

### 10.7 缓动编号事故（务必记住）

`easingType` 官方表：**2=OutSine、3=InSine、4=OutQuad、5=InQuad、8=OutCubic、9=InCubic**。
把"缓出"写成 3/5/9，引擎会按"缓入"解释——判定线会在动作末尾突然撞停，
观感就是"死板、不灵活"。本地预览脚本也必须用同一张表，否则预览与实机不一致。

## 11. 演出术语速查

| 术语 | 英文 / 日文 | 做法 | 用途 |
|---|---|---|---|
| 断线 / 透明线 | hidden line / 透明判定線 | 线 alpha→0，音符保持 | 留白、空灵段 |
| 浮空 note / 假 note | floating notes | 音符挂在不可见线上，照常下落 | 无参照的"天外之音" |
| 音符代替判定线 | ノーツが判定線 / notes-as-line | 不可见线 + `speed=0` 的音符停在线上 | 用音符画出判定位置 |
| 扫线 / 刮奏墙 | line sweep | `moveX` 连续横移，线上铺密集 Tap | 琵琶/吉他刮奏、过场 |
| 频闪 | strobe | alpha 0↔255、rot 0↔90°，1/4 拍一次 | 鼓点抽空、BPM 切换 |
| 双线轮班 / 换线 | line relay / handoff | 旧线淡出并开走，新线在强拍亮起 | 段落切换、双声部 |
| 天顶线 | ceiling line | `rotate 180° + moveY +` | 音符从上方落、翻转世界 |
| 蛇形 Drag / 滑音串 | drag curve / gliss | 1/8 拍内用 Drag 采样一条曲线 | 滑音、连奏、走句 |
| 锁指 / 颤音 Hold | hold anchor / trill | 两点短 Hold 交替（≤0.4 拍） | 轮指、持续音 |
| 留白 | negative space | 整段撤走可见音符，只留运镜 | 情感停顿、呼吸 |
| 运镜 | camera move | moveX/Y + rotate + 缓动组合 | 空间感、段落推进 |
| 视差 | parallax | 多层贴图以不同幅度平移 | 伪 3D 纵深 |
| 强拍换气 | downbeat handoff | 所有切换落在小节强拍 | 不打断读谱 |
| 段落色 | section texture | 用类型比例/密度/位移定义段落 | verse/chorus 对比 |
| 拍点骨架 | beat backbone | 先定"每拍 1 音 / 每拍 1 和弦 / 16 分流" | 决定整曲手感 |
| 全正拍 | on-beat only | 所有真 note 都落在 1/4 拍 | 舒服、可跟唱 |
| 拍点和弦 | beat-chord | 每个整数拍放一组 2–6 押 | Lv.12–13 的稳定节奏 |
| 假 note 光柱 | fake-note bloom | 同 x 叠几十个 size↑/alpha↓ 的假 Hold | 重音烟花、转段爆发 |
| 叠线发光 | line glow stack | 2–3 条线完全重叠，alpha 255/168/88 | 粗线光晕（单线谱改用发光贴图） |
| 呼唤—回应 | call & response | 左右远位单音交替，一问一答 | 前奏、主歌叙事 |
| 发射器线 | emitter line | alpha=0 的线，note 在 x=0，靠线位置/角度撒音符 | 全屏雨滴、无参照音符 |
| 线即轨迹 | line-as-path | 音符下落时旋转/平移线 | 弧线、螺旋、摆动 |
| 拟物化 | objectification | 先定"像什么"，再选 note 类型与线姿态 | 雨/光柱/水花/隧道 |
| 光柱 / 雨柱 | light pillar | 长假 Hold + speed 脉冲 + 低 alpha | 重音、收尾、空间柱 |
| 速度视差 | speed parallax | 同拍 note 用不同 speed | 远近层次、3D |
| 速度脉冲 | speed spike | speed 瞬时到 1000 再复位 | 瞬现、闪现、重置 |
| 倒流雨 | rising rain | 线 180° + 低速 note | 尾奏、倒放、情绪反转 |
| 扇阵 / 星芒 | fan burst | N 条线共原点、角度等分 | 灭点、爆发、法阵 |
| 线框空间 | wireframe room | 0°/90° 长线交叉 | 伪 3D 房间、隧道 |
| 微呼吸 | micro-sway | ±2~4°、±20 px 规律微动 | 静止段的生命感 |
| 叠音 / 接音 | note stacking / catcher | 同点叠多颗 / 大 Hold 当容器 | 光柱、雨柱、接雨 |
| 背景同构 | background echo | 线的主方向 = 插画主方向 | 谱面与封面浑然一体 |
| 交叉淡化换材质 | texture crossfade | 两条重合线 alpha 互换 | 中途"换皮肤"（谱内） |
