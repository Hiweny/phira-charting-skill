# 09 · 高分谱面案例拆解（Case Studies）

> 目的：把参考谱的**表现手法**拆成可复用的"动作 + 参数 + 时机"，下次制谱可以直接复现，而不是凭感觉模仿。
> 每份案例按同一结构记录：数据体检 → 结构编舞 → 与歌曲的对应 → 可移植技法 → 复现配方 → 坑。

---

## 案例一：《琵琶行（Full ver.）》

- 文件：`40813927.json`（RPE 1.13 导出）+ `info.yml`
- 曲长：326 s；BPM：160 → 176 → 164 → 168 → 176（5 段）
- 难度：IN Lv.15.4；30 条判定线；2024 notes
- 一句话总结：**用"消失的线"讲留白，用"会动的线"讲琵琶。**

### 1.1 数据体检

| 指标 | 数值 | 说明 |
|---|---|---|
| notes | 2024 | 326 s 内，整体约 6.2 NPS |
| 类型占比 | Tap 54.9% / Drag 25.4% / Flick 13.4% / Hold 6.2% | Drag 占四分之一，是"滑音"的载体 |
| x 网格 | 0, ±135, ±270, ±405, ±540（副线 ±675） | **135 px 一格，共 8 轨 + 2 个越界轨** |
| 和弦簇 | 584 组，最大 13 押 | 重音用宽位多押，不做随机散点 |
| Hold 时长 | 中位 0.34 s，最长 7.16 s | 短 Hold 是锁指，长 Hold 只用于收尾 |
| Drag 时长 | 全部 0（瞬时） | Drag 只做"碰到即可"的滑动，不做长条 |
| 判定线 | 30 条，全部默认 `line.png` | **零自定义贴图，全靠线与透明度编舞** |
| 透明线上的音符 | 384 个（19%） | 视觉上像"假 note"；本例 `isFake` 仍为 0，**可判定** |

### 1.2 结构：不是双线同屏，而是"双线轮班"

两条主 Play 线 L0 / L1 都是全宽（±540），但**几乎不同时出音符**（±60 ms 内同时出现仅 56 次，占 L0 的 5.9%）。它们像两位乐手轮流上台：

| 时间 | 在台前 | 另一条在做什么 |
|---|---|---|
| 6–65 s | L0（alpha 150，y=-250） | L1 透明待机 |
| 65–85 s | L1（alpha 150） | L0 alpha→0 |
| 85–90 s | L0 从 (x=278,y=288,rot=30°) 飞入 | 一次"甩线入场" |
| 90–110 s | L0 被甩到 y=1000 / x=-900 离场 | L1 以 alpha 100 独奏 |
| 125–165 s | **L0 停在 x=-600, y=400, rot=90°, alpha=0** | L1 正常演奏 |
| 165–180 s | L0 归位 alpha 200 | L1 淡出 |
| 180–193 s | L0 可见但**一个音符都没有** | L1 alpha=0，**音符继续落** |
| 195 s | L0 竖成 90° 并淡出 | L1 alpha 150 接手 |
| 231–236 s | 两条线一起 4 Hz 频闪 | BPM 转换 |
| 240–310 s | L0 alpha 200 主奏 | L1 待机 / 结尾竖线 |

要点：
- **不用的线不是简单 alpha=0，而是"开走"**（x/y 丢到 ±600~1000 外），画面里不会有残留的半截线。
- **换线永远发生在段落强拍**，先淡出旧的、再亮新的，读谱不会断。
- 旋转集中在**稀疏段 / 间奏**；密集段回正到 0°，保证可读。

### 1.3 与歌曲"浑然一体"的 5 个瞬间

| 时间 | 音乐 | 谱面动作 | 手法名 |
|---|---|---|---|
| 100.9–106.4 s | 琵琶单音、留白 | 线 alpha=0，Drag 在 ±540 每 0.7 s 左右交替 | **断线摆钟**（只剩两根"弦"在响） |
| 177.3–179.0 s | 琵琶快速刮奏 | 一条**可见**线从 x=100 横扫到 459，线上挂满 Tap 墙 | **扫线 / 刮奏墙**（线就是拨片） |
| 180.0–181.7 s | 余音、声场拉开 | 一条**不可见**线从 x=-675 扫到 -253，音符 x 固定 | **浮空音簇**（音符横着漂，没有线） |
| 208.6–209.7 s | 密集轮指 | ±405 两点上 16 个 0.34 s 短 Hold | **锁指颤音** |
| 210.0–212.4 s | 连续滑音 | 32 个 Drag 采样出一条 0→540→0→-135→72 的曲线 | **蛇形 Drag / 滑音串** |
| 231.8–235.8 s | BPM 切换、鼓点抽空 | 主线 alpha 0↔150、rot 0°↔90°、x 跳到 -450，约 4 Hz | **频闪**（视觉替鼓） |
| 175.9 s | 乐句翻高 | 线 rot=180、y=+250，Drag 在 ±540 | **天顶线**（音符从上方落） |

### 1.4 "此时无声胜有声"到底怎么做的

不是把音符删掉，而是**把承载音符的线变成透明**：

1. L0（玩家看得见的那条线）alpha=200，但 **0 个音符**；
2. L1 alpha=0，却继续按旋律铺 Tap / Drag / Flick；
3. 玩家看到的是：**音符从黑暗里掉下来，没有线可以参照**——像"假 note"，但依然可打。

RPE 里判定线透明度**不会让音符消失**（音符有自己的 alpha），所以这是安全的表演，而不是"盲打"。

> 术语：日文 Phigros Wiki 把这种做法叫「ノーツが判定線」（音符代替判定线）；
> 中文社区常说 **断线、透明线、浮空 note、假 note**。
> 官方谱也常用它做"两个音符重合时打击"——把一条线藏在音符下面。

### 1.5 可移植到"单线谱"的配方

我们的《君自故乡来》只有一条 Play 线，也能复现大部分效果：

| 原谱手法 | 单线复现方式 |
|---|---|
| 双线轮班 | 单线在段落强拍 **alpha 0 → 瞬移 → alpha 255**，一次"换气" |
| 断线摆钟 | 间奏把主线 alpha 降到 0，只留 ±420 的 Drag 交替 |
| 浮空音簇 | 桥段 2 小节 alpha=0，音符照常落；演出线（星芒）继续转 |
| 扫线 | 主线 `movex` 从 -600 扫到 +600，同时铺一段 16 分跑动 |
| 蛇形 Drag | 用 1/8 拍间隔的 Drag 采样一条正弦/抛物线 |
| 频闪 | BPM 变化或鼓点抽空处，alpha 0/255 以 1/4 拍闪烁 1 小节 |
| 天顶线 | `rotate 180° + movey +350`，让音符从上方落下 |
| 锁指颤音 | ±280 两点各放 0.4 拍短 Hold，交替 4 次 |

### 1.6 坑

- **不要把频闪放在密集段**：4 Hz 闪烁 + 16 分会直接晕。
- **透明线期间不要放大角度旋转**：玩家失去参照，旋转会让人找不到判定位置。
- **Drag 曲线采样要够密**（1/8 拍以内），否则会变成"折线"而不是滑音。
- **换线/换气必须留一个可预期的重音**（和弦或 Flick），否则玩家会觉得"谱面断了"。
- 长 Hold（>1 s）只在收尾用；中段长 Hold 会被误读成第二条判定线。

## 案例二：《放空》IN Lv.13

- 文件：`0199424804115775.json`（RPE 1.7.0）+ `info.yml`
- 曲长：150.7 s；BPM：118 恒定；难度：IN Lv.13.0；30 条判定线
- 一句话总结：**把"节奏"做成每拍一个和弦，把"华丽"交给不吃判定的假 note。**

### 2.1 数据体检

| 指标 | 数值 | 说明 |
|---|---|---|
| notes | 1664 | 看起来 11 NPS，但… |
| **假 note** | **992（59.6%）** | 其中 96.6% 是 Hold |
| 真 note | 672 | 实际可玩密度仅 **4.5 NPS** |
| 真 note 类型 | Tap 69% / Drag 16.2% / Hold 8.5% / Flick 6.2% | 以点为主，滑为辅 |
| 真 note 时间 | **100% 落在整数拍上** | 没有一个反拍 |
| 真 note x | **100% 落在 75 px 网格**（±75…±525） | 15 条隐形轨道 |
| 真 note 间隔 | 229 个正间隔里 221 个 = **正好 1 拍** | 每拍最多一个和弦 |
| 和弦簇 | 208 组，2–6 押（3 押最多，105 组） | 拍点重音 |
| 主 Play 线 | 4 条（L0–L3），轮流值班 | 叠线发光 |
| 演出线 | 10 条零音符线（L4–L13） | 对称 / 对角线阵型 |

### 2.2 为什么"玩起来很舒服"

1. **全正拍**：所有真 note 都在 1/4 拍上，玩家永远跟着鼓点动手，不需要切分。
2. **一拍一和弦**：一拍只出现一组 2–6 押，打完就有接近半秒的呼吸。
3. **固定网格**：75 px 一格，左右手每次都落在熟悉的点上，形成肌肉记忆。
4. **假 note 补视觉**：屏幕看起来很满，但手只需要按拍点和弦——眼睛忙、手不忙。
5. **线条永远好看**：L0/L2/L3 以 255 / 168 / 88 三层完全重叠，视觉上是一根发光的粗线。

> 这就是 Lv.13 的"舒适"配方：**降低手的工作量，提高眼的获得量。**

### 2.3 段落结构

| 时间 | 真 note | 假 note | 编舞 |
|---|---|---|---|
| 0–10 s | 0 | 0 | 只有轻微运镜，等前奏 |
| 10–40 s | 每拍 1 音，左右远跳（±375/±450） | 7 | L0 单线，像"呼唤—回应" |
| 40–110 s | **每拍 1 组和弦**，17–20/20 拍有音 | 0–2 | L1 主奏，L0/L2/L3 交替叠亮 |
| 110–130 s | 仍然每拍有和弦 | **192 → 576** | 假 note 光柱爆发，真谱保持简单 |
| 130–150 s | 只有 7 个 Drag | 208 | **放手**：玩家看收尾烟花 |

### 2.4 三个可直接复现的手法

#### A. 拍点和弦（Beat-Chord Backbone）

```text
拍：  1    2    3    4
音： [3押] [2押]  -   [4押]
x：  ±225  ±450      -225/0/300/450
```

- 每个和弦都落在整数拍；
- 和弦宽度优先用 0 / ±225 / ±450（75 的倍数），保持"可预判"；
- 最多 1 拍空一次，连续空 2 拍只用于段落收尾。

#### B. 假 note 光柱（Fake-note Bloom）

《放空》的假 note 不是"铺满屏幕"，而是**在同一个 x 叠几十个不同 size / alpha 的假 Hold**：

| 参数 | 取值 | 作用 |
|---|---|---|
| x | 固定一个点（如 -225） | 光柱位置 |
| size | 0.94 → 2.77 递增 | 由细到粗的"绽放" |
| alpha | 94 → 52 递减 | 边缘更柔 |
| above | 0 与 1 交替 | 线的两侧同时发光 |
| 时长 | 0–0.5 s | 短促的亮点 |

一个 0.05 s 的瞬间叠 64 个，就得到一道发光柱。**全部是假 note，不参与判定。**

#### C. 叠线发光（Line Glow Stack）

- L0 alpha 255、L2 alpha 168、L3 alpha 88，三条线**位置/角度完全相同**；
- 视觉上不是三条线，而是一根带光晕的线；
- 需要"换线"时，只改 alpha 权重（255/168/88 → 0/0/255），像调音台推子。

> 如果项目要求"只能有一条判定线"（我们的《君自故乡来》），
> 不要用三条线叠；改用**自绘发光贴图**（中间实心 + 外圈 glow）达到同样效果。

### 2.5 演出线的几何阵型

| 线组 | 阵型 | 参数 |
|---|---|---|
| L6 / L7 | **点对称双线** | (∓447, ±200)，同角度 -30°→90° |
| L8 / L9 | 更外一圈的点对称 | (∓595, ±400)，alpha 只有 21–64 |
| L10–L13 | **对角线四重奏** | 四点落在同一条斜线上，角度 -45°~-52.5° |
| L4 / L5 | 单侧"甩线" | x 可到 ±600，alpha 255 |

规律：**成对出现、绕中心点对称、共享同一个旋转角**。这就是"几何美感"最省力的做法。

### 2.6 移植到《君自故乡来》的配方

| 《放空》手法 | 单线 Lv.12–13 复现 |
|---|---|
| 全正拍 | 主歌/副歌骨架改成 **每拍一个音或和弦**，16 分只留在句尾 |
| 一拍一和弦 | 重音拍用 ±280 双押，弱拍单音，留半拍呼吸 |
| 75 px 网格 | 我们的 140 px 七轨等价，保持相邻位移 ≤2 轨 |
| 假 note 光柱 | 在重音/转段处，用 8–16 个 size/alpha 递减的**假 Hold** 叠一道光柱 |
| 叠线发光 | 用自绘发光贴图替代三条线 |
| 点对称双线 | 两条零音符演出线，位置 (x,y) 与 (-x,-y) 镜像，同角度旋转 |
| 放手收尾 | 最后 2 小节真 note 降到 1–2 个/拍，让假 note 烟花接管 |

### 2.7 坑

- **假 note 不能承担节奏引导**：玩家不会去数它们，真谱必须有清晰的拍点。
- **假 note 不要放在判定线上遮住真 note**：把光柱放在 x=±450 或 y 偏移处。
- **全正拍不等于每拍都塞满**：连续 8 小节每拍 4 押会变成体力活，必须有 1 拍空。
- `isFake=1` 的 note 不计物量、不计分；写难度时必须用**真 note** 统计。
- RPE 1.7 的 `multiLineString` / `multiScale` 是编辑器级联动，导出到 Phira 可能丢失；
  跨引擎复现时用**独立镜像线**代替。

## 两案例对照：两种"浑然一体"

| 维度 | 琵琶行 Lv.15.4 | 放空 Lv.13 |
|---|---|---|
| 核心手段 | 断线、浮空 note、双线轮班 | 全正拍和弦、假 note 光柱、叠线 |
| 与歌同步方式 | **跟着乐句走**：刮奏→扫线，留白→断线 | **跟着鼓点走**：每拍一个和弦 |
| 难度来源 | 读谱 + 位移 + 换线 | 拍点稳定 + 少量宽位和弦 |
| 视觉密度 | 高（线多、变化大） | 高（假 note 多） |
| 手的工作量 | 高 | 低 |
| 可移植到单线 | 断线/扫线/频闪/蛇形 Drag | 拍点和弦/假 note 光柱/镜像演出线 |

**统一方法论**（下次制谱按这个顺序）：

1. **拍点骨架**：先决定"每拍一个音 / 每拍一个和弦 / 16 分流"，这决定手感。
2. **留白地图**：标出前奏、间奏、静默句，决定哪里撤音符、哪里断线。
3. **演出设计**：给留白段配几何动作（扫线、天顶线、六星芒、频闪）。
4. **假 note 烟花**：只在重音/转段加，绝不参与难度。
5. **最后才加花**：16 分、Flick、宽位和弦，永远最后加，且要能被前四步解释。
