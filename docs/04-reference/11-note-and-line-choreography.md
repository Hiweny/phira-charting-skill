# 11 · 让 note 与判定线"活过来"——轨迹、拟物化与 3D 纵深

> 这份文档回答一个比"怎么摆 note"更根本的问题：
> **note 为什么只能直直下落？判定线为什么只能横着？**
> 答案：都不是。引擎本来就允许它们像任何东西、走任何轨迹——只是大多数谱师没有用。
>
> 本手册把《时落之雨》《琵琶行》《放空》里出现过的手法，
> 加上 Phigros 官方机制，整理成可复现的"物体配方"。

---

## 1. 先理解引擎：note 的位置是"算"出来的

RPE / Phira 的 note 没有"独立轨迹"字段。每一帧：

```text
note_screen(t) = line_pos(t) + R(line_rot(t)) · (note_x, -d(t))
d(t) = ∫ line_speed(t) · note_speed(t) dt
```

结论：

1. **你动线，就等于动所有空中的 note。** 线旋转 = note 画弧；线平移 = note 整体漂移。
2. **`note.speed` 是每颗 note 的独立速度倍率。** 同一时刻不同 speed = 不同远近/不同到达时间。
3. **`above=2` 让 note 落在线的另一侧。** 配合 180° 翻转，可以做"天地颠倒"。
4. **`isFake=1` 只取消判定，不取消渲染。** 假 note 是最好的免费演员。
5. **线 alpha 与 note alpha 独立。** 线透明了，note 照样显示、照样判定（这是"断线/浮空"的底层原理）。

> 官方描述（Phigros Wiki）：note 可以 **move in any direction, rotate/spin, change speed,
> move to a different position before being judged, move in an arc, jump on the judgement line**。
> 判定线宽度约为屏幕 250%，可平移、旋转、出现/消失，也可以只作装饰或提示音符出现位置。
> 来源：<https://phigros.fandom.com/wiki/Game_Mechanics>、
> <https://phigros.fandom.com/zh/wiki/游戏内容>、
> <https://wikiwiki.jp/phigros-fnmd/谱面制作>

## 2. 四条"活"法则

### 法则一：给线一个身份（发射器 / 轨迹作者 / 光栅 / 灭点）

不要问"这条线放哪"，要问"这条线在演什么"：

| 身份 | 它做什么 | 参数特征 |
|---|---|---|
| **演奏线** | 承载真 note，保证可读 | alpha 150~255，角度克制 |
| **发射器线** | 零 note 或 1 颗 note，把音符撒到任意位置 | alpha 0，note 在 `x=0`，线可任意旋转 |
| **轨迹作者** | 在空中旋转/平移，改变所有 note 的路径 | 旋转 ±90°~±540°，与重音对齐 |
| **光栅/雨丝** | 超长线斜穿画面，只做视觉 | 角度与背景主方向一致，alpha 40~150 |
| **灭点/扇阵** | 多条线共原点，制造透视 | 同一 `(x,y)`，角度等分 |
| **光柱** | 长 Hold + 速度脉冲，瞬现 | `speed=1000`，假 note，低 alpha |

### 法则二：先拟物，再配参数

先说出"这是什么"，参数自然就出来了：

| 想演的东西 | note 选型 | 线怎么配合 | 关键参数 |
|---|---|---|---|
| **雨滴** | Drag，0 时长，size 0.4~0.7 | 发射器线，角度 = 雨的方向 | speed 0.5~1.5 分档 |
| **雨柱/光柱** | 假 Hold，2~9 s | 线 alpha=0，按拍瞬移 | `speed=1000`，note alpha 20~60 |
| **瀑布** | 一排 Hold，长短错落 | 横线缓慢下移 | 每根 speed 不同 |
| **水花/溅射** | 假 Drag/Flick，从同一点发散 | 扇阵线，角度 0°~180° | 每颗 x 相同、线角度不同 |
| **星芒/法阵** | 假 note 沿圆周 | N 条线共原点，角度 360/N | N=6/8/12，OutElastic |
| **隧道** | 真假 note 混合，由远及近 | 两组线框，一组缩小一组放大 | speed 0.2→3.0 渐变 |
| **镜面/倒影** | `above=2` | 线翻转 180° | note alpha 减半 |
| **雨停/水汽上升** | 假 Hold，低速 | 线 180°、alpha=0、y 偏下 | speed 0.2~0.7 |
| **心跳/呼吸** | 每拍单音 | 线 ±2~4°、±20 px 微动 | OutQuad/InQuad 交替 |

### 法则三：一个动作只服务一个重音

- 线的大动作（翻转/扇阵/坠落）**落在段落强拍**；
- 密集段线要稳（角度变化 ≤ ±4°），稀疏段才做大幅旋转；
- 同一时刻最多两个因子爆表（密度、旋转、位移、透明度），第三个必须收。

### 法则四：留白也是演出

- 前奏可以 0 真 note，只放 3~5 颗假雨滴；
- 间奏把演奏线 alpha 降到 0，让"音符从黑暗里落下"；
- 收尾把真 note 减到 1~2 颗/拍，让光柱/扇阵接管。
- **玩家记住的往往是"什么都没有的那两秒"。**

## 3. 轨迹：五种"千变万化"的实现

| 轨迹 | 实现 | 例子 |
|---|---|---|
| **直线斜落** | 线固定角度 θ | 雨丝方向与插画一致 |
| **圆弧** | note 下落期间线匀速旋转 | L2 在 129.7 s 转 90° |
| **螺旋** | 线转 ±540°，note 还在空中 | 《时落之雨》L7–L9 暴雨段 |
| **折线/弹跳** | 线用 OutBounce / OutElastic 改变角度 | 扇阵呼吸、门框回弹 |
| **瞬移/闪现** | `speed` 脉冲到 1000 再回 0 | 光柱、雨柱 |
| **倒流** | 线 180° 或 `speed` 为负 | 尾奏上升雨 |

**复现模板（螺旋雨）**：

```python
# 让线在 4 拍内转 180°，同时每 1/2 拍落一颗 Drag
line.rotate([(bt(bar,0), 0), (bt(bar+4,0), 180, easing=1)])
for k in range(8):
    line.notes.append(note(4, bt(bar,0)+k*0.5, x=0, speed=1.0))
```

> 注意：旋转中的线会让**落点**也旋转。
> 如果这段需要精确读谱，先把线转到目标角度，再让重音落下；
> 旋转只放在过门/演出段。

## 4. 3D 纵深：不靠贴图的四种"真参与"

| 方法 | 原理 | 演奏上的体现 |
|---|---|---|
| **灭点扇阵** | N 条线共原点、角度等分 | 音符从同一个"地平线点"向四周落 |
| **速度视差** | 同拍 note 用不同 speed | 近处快、远处慢，形成前后层 |
| **线框空间** | 0°/90° 长线交叉成网格 | 玩家在"房间"里打，落点有透视 |
| **出屏运镜** | 线移到 y=±2000 / x=±800 再回来 | 镜头切走/切回，段落感 |

再加两个便宜技巧：

- **翻转地平线**：线 0°→180°，音符从上方落下（`above=1`）或从下方升起（`above=2`）。
- **纹理交叉淡化**：两条线位置/角度完全重合，用 alpha 交叉淡化不同 `Texture`，
  等价于"中途换皮肤/换材质"（Phira 不支持中途换全局皮肤，这是谱内唯一可靠的替代）。

**判定线组成立体几何的最小配方**：

```text
立方体（伪）：2 条横线（y=±300）+ 2 条竖线（x=±420）+ 1 条斜线（45°）贯穿
六星芒：3 条线，角度 0°/60°/120°，共原点，反向自转
隧道：两组同心矩形框，外框 alpha 40、内框 alpha 100，整体缓慢放大
```

## 5. "一个 note 接住其他 note"

这是社区里常说的**叠音 / 接音**，有三种可靠做法：

### 5.1 大 Head + 长 Body 当"容器"

- 在同一个 `x`、同一个时间放一颗 **size 1.4~2.0 的 Hold**；
- 后续 note 落在同一个 `x`，时间落在 Hold 的持续区间内；
- 视觉上像"雨落进一根管子/一只手接住"。

```python
N(main, H, b, x=0, end=b+2.0, size=1.8, alpha=200)
for k in range(4):
    N(main, T, b+0.5*k, x=0, size=0.8)
```

护栏：容器 Hold 的 `alpha` 不要太高（≤ 200），否则会遮住里面的 note；
真 note 不要和容器同拍同 x 完全重合（会读成双押）。

### 5.2 假 Hold 当"网"

- 一条 alpha=0 的线 + 1 个长假 Hold（2~4 s）+ `speed=1000`；
- 让真 note 从它旁边落下，视觉上"穿过光柱"；
- 假 Hold 不判定，纯装饰，不会误触。

### 5.3 同点叠几十颗（光柱/烟花）

- 同一个 `(line, x)`，同一个 `startTime`，叠 8~64 颗假 Hold；
- 每颗 `size` 递增、`alpha` 递减、`above` 交替；
- 一颗 0.05 s 的"爆发"，或 8 s 的"常驻光柱"。

```python
for k in range(16):
    N(fx, H, b, x=0, end=b+0.08, size=0.9+0.1*k, alpha=max(20, 90-4*k), isFake=1)
```

> 《时落之雨》的 24 根雨柱、《放空》的 64 颗光柱，都是这个配方。

## 6. 与歌曲"浑然一体"的设计流程

```text
① 读插画/封面：主色、主方向、母题（雨/海/星空/机械）
② 定 1 个视觉母题：整首只用一套（雨滴→雨柱→雨停）
③ 划段落：前奏/主歌/副歌/桥段/高潮/尾奏，每段一个"视觉重心"
④ 给每段配"物体"：这段是雨滴、扇阵、光柱还是线框？
⑤ 定拍点骨架：每拍 1 音 / 1 和弦 / 16 分流（决定手感）
⑥ 先放演奏线，再放演出线；演出线全部零 note
⑦ 用假 note 做烟花，最后才加真 note 的花
⑧ 自检 + 真机/高质量渲染逐帧看
```

**母题一致性检查**：如果一段在演"雨"、下一段突然演"机械齿轮"，
不是不可以，但必须有音乐上的理由（转调、曲风切换、念白）。
否则观众读到的是"堆特效"，不是"作品"。

## 7. 参数预算（Lv.12–13，单演奏线）

| 维度 | 建议值 | 超了会怎样 |
|---|---|---|
| 真 note 密度 | 主歌 2.5~3.5 NPS；副歌 4~6 NPS | 超过 7 且无留白 → 体力谱 |
| 假 note 数量 | 真 note 的 0.3~1.5 倍 | 太多会遮住真 note |
| 演奏线 alpha | 150~220 | 255 + 白线 → 刺眼；<100 → 读谱困难 |
| 演奏线角度 | 密集段 ±4°；稀疏段可 ±90°~180° | 密集段大角度旋转 → 晕 |
| 单段最大旋转 | ±180°（2 小节内） | ±540° 只用于发射器/演出线 |
| 演出线数量 | 4~12 条 | 20+ 条在移动端易掉帧 |
| 光柱数量 | 4~8 根同屏 | 24 根是 15.4 难度谱的余量 |
| 微呼吸幅度 | ±2~4°、±20 px | 幅度大于 ±10° 就不再是"呼吸" |
| 速度视差档位 | 0.5 / 0.8 / 1.2 / 2.0 | 同一和弦内不要超过 3 档 |

## 8. 术语速查（新增）

| 术语 | 英文/日文 | 做法 | 用途 |
|---|---|---|---|
| 发射器线 | emitter line | alpha=0 的线，note 在 x=0，靠线位置/角度撒音符 | 全屏雨滴、无参照音符 |
| 线即轨迹 | line-as-path | 音符下落时旋转/平移线 | 弧线、螺旋、摆动 |
| 拟物化 | objectification | 先定"像什么"，再选 note 类型与线姿态 | 雨/光柱/水花/隧道 |
| 光柱 / 雨柱 | light pillar | 长假 Hold + speed 脉冲 + 低 alpha | 重音、收尾、空间柱 |
| 速度视差 | speed parallax | 同拍 note 用不同 speed | 远近层次、3D |
| 速度脉冲 | speed spike | speed 瞬时到 1000 再复位 | 瞬现、闪现、重置 |
| 倒流雨 | rising rain | 线 180° + 低速 note | 尾奏、倒放、情绪反转 |
| 扇阵 / 星芒 | fan burst | N 条线共原点、角度等分 | 灭点、爆发、法阵 |
| 线框空间 | wireframe room | 0°/90° 长线交叉 | 伪 3D 房间、隧道 |
| 微呼吸 | micro-sway | ±2~4°、±20 px 规律微动 | 静止段的生命感 |
| 叠音 / 接音 | note stacking / catcher | 同点叠多颗 / 大 Hold 当容器 | 光柱、雨柱、接雨 |
| 背景同构 | background echo | 线的主方向 = 插画主方向 | 谱面与封面浑然一体 |
| 交叉淡化换材质 | texture crossfade | 两条重合线 alpha 互换 | 中途"换皮肤"（谱内） |

> 这些术语一部分来自社区口语，一部分是本手册为了方便复现而命名的；
> 官方只保证机制（note 可任意移动/旋转/变速/走弧线；线可平移/旋转/显隐），
> 不保证叫法统一。写文档时以"做法 + 参数"为准，不要纠结名字。

## 9. 单线谱怎么用这一整套

| 想要的效果 | 单线做法 | 风险 |
|---|---|---|
| 雨滴 | 主线 alpha 降到 0~80，Drag + 变速 | 长时间透明会失去参照，≤ 2 小节 |
| 光柱 | 零音符线 + 假 Hold + speed 1000 | 假 note 遮住真 note |
| 扇阵 | 8 条零音符线共原点 | 线太多，移动端掉帧 |
| 线框 | 2 横 + 2 竖零音符线 | 与主演奏线混淆 → 演出线 alpha ≤ 100 |
| 螺旋 | 主线在稀疏段慢转 90° | 密集段禁用 |
| 翻转 | 主线 180°，2 小节后翻回 | 翻回时必须落在强拍 |
| 呼吸 | 主线 ±3°、±20 px | 幅度过大会晕 |

**底线**：演奏线永远只有 1 条；演出线永远 0 个真 note；
所有"活"的动作都要能在音乐里找到对应的那一拍。
