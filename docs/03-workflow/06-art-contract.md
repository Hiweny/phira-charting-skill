# 06 · 主人钦定的审美契约（Art Direction Contract）

> 这份文档把主人在多轮制谱中提出的**明确意见**固化下来。
> 它优先于手册里的"建议值"；下一次接手的 Agent 必须先读这一页，再动笔。
>
> 记录日期：2026-11-22（持续追加）

---

## 1. 七条硬约束

### ① 一条演奏线

- **原话要点**："不要弄两条判定线在那放着，用一条就行了。"
- 落地：承载真 note 的线**永远只有 1 条**；其余线一律零音符或只放 `isFake=1`。
- 验收：任意时刻，同时承载真 note 的线数 = 1。

### ② 难度 12–13

- **原话要点**："难度介于 12 到 13。"
- 落地：真 note 密度主歌 2.5~3.5 NPS、副歌 4~6 NPS；峰值 1 s 滑窗 ≤ 13。
- 验收：`chart_stats.py` 的 real NPS 与标称难度匹配；不靠假 note 充数。

### ③ 判定线要有生命、要有几何美

- **原话要点**："判定线还是有点死板不够灵活""要让判定线产生几何美感，
  比如垂直，比如用判定线画六星芒进行旋转，甚至用二维判定线和 note 营造三维空间。"
- 落地：每段至少一次"线在动"（旋转/位移/呼吸）；优先使用
  0°/90° 垂直门、60° 六星芒、扇阵、线框房间、透视隧道。
- 验收：全谱判定线角度跨度 ≥ 100°；相邻段落构图不重复；联系表里不能 8/12 帧同构图。

### ④ 3D 要参与演奏，不只是贴图

- **原话要点**："3D 效果不仅仅是贴图，更要参与到演奏：note 可以由远及近，
  判定线可以组成立体几何，可以向内向外纵深。"
- 落地：用**速度视差**（同拍不同 speed）、**灭点扇阵**、**线框空间**、
  **出屏运镜**；不要只加一张背景图。
- 验收：抽掉贴图后，画面仍然有前后层次和空间方向。

### ⑤ note 与线要"活"，轨迹要优雅，能拟物

- **原话要点**："note 和判定线活过来，每个 note 和判定线都可以很灵活，
  轨迹都要优雅；可以把它们拟物化，比如 note 当雨滴，也可以用多个/多种 note
  结合画出更多物体来参与表演或交互；note 轨迹不一定垂直下落，可以千变万化。"
- 落地：先定母题（雨/海/星/机械），再选 note 类型与线姿态；
  用发射器线、线旋转、速度分层来写轨迹；用叠音/光柱/扇阵"画物体"。
- 验收：每个段落能用一句话说出"这段在演什么"；不是"这里塞了 16 分"。

### ⑥ 谱面与歌曲浑然一体

- **原话要点**："怎么把谱面表现和歌曲相应和，让谱面和歌曲浑然一体，
  比如《琵琶行》无声胜有声的地方。"
- 落地：段落强拍做切换；留白段撤音符/断线；刮奏配扫线；雨声配雨滴；
  背景主方向决定线的基准角度。
- 验收：关掉音乐看谱面，能看出段落；关掉画面听音乐，能感到谱面在"跟"。

### ⑦ 歌词要贴人声、及时消失

- **原话要点**："歌词嵌入得生硬无比，还没跟上节奏还半天不消失。"
- 落地：逐字/逐词跟拍；最后一句后最多停 1.15 拍，0.35 拍淡出；
  位置固定在下方 y≈-300~-360，避免与 note 抢视线。
- 验收：歌词结束时间 - 人声结束时间 ≤ 1.2 拍。

## 2. 手感与节奏：主人明确夸过的

- **《放空》"玩起来很舒服"** → 全正拍 + 每拍一个 2~6 押和弦 + 75 px 固定网格 +
  假 note 只做视觉。**降低手的工作量，提高眼的获得量。**
- **《君自故乡来》v5 "几乎挑不出毛病"** → 单线、七轨、相邻位移 ≤ 2 轨、
  和弦占比 26%、峰值 NPS ≈ 8。
- 结论：主人偏好的手感是**稳定的拍点骨架 + 可预期的落点 + 少量宽位和弦**，
  不是"手指体操"。

## 3. 工作方式（主人明确要求）

1. **能自动执行的就直接执行**，不要每一步都问；完成后汇报"做了什么/什么效果/怎么改"。
2. **研究要举一反三**：不要"我说哪你看哪"；要主动找同类手法、联网核对术语。
3. **不要只看数据**：要看 note 与线**合起来**的效果；数据只是证据。
4. **不要止步于代码**：自检要看到画面与手感；本地预览不够就上真实引擎。
5. **skill 是给下一个 Agent 用的**：信息要够、要能持续迭代；研究完及时沉淀并 push。
6. **改规则/改 skill 的最终写入权属于主人**；但"沉淀研究结论"可以直接做并推送。

## 4. 被主人否决过的做法

| 做法 | 为什么被否决 |
|---|---|
| 多条线同时出音符 | 不知道该看哪条，读谱成本爆炸 |
| 判定线全程水平不动 | "死板、不灵活" |
| 只按歌词铺音符、没有鼓点骨架 | 没有演奏感 |
| 歌词整句砸出、挂到下一句 | 生硬、跟不上、不消失 |
| 只分析 JSON 数据、不看合成画面 | 学不到"合起来的效果" |
| 用粗糙预览器冒充实机验证 | 看不到皮肤、打击特效、真实手感 |

## 5. 交付前必须回答的 8 个问题

1. 这段在演什么？（一句话母题）
2. 演奏线是否只有 1 条？
3. 每个段落的强拍上，线做了什么？
4. 3D 是靠什么成立的？（扇阵/视差/线框/出屏，至少两个）
5. 留白在哪里？留白时玩家看什么？
6. 歌词最后一字之后停多久？
7. 真 note 的峰值 NPS 是多少？和弦占比多少？
8. 在真实引擎/高质量渲染里，有没有出现遮 note、闪线、掉帧？

> 8 个问题里任何一个答不上来，就不算交付。
